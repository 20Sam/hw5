# Campus Customs board (React + Vite + TypeScript)

```bash
npm install
npm run dev
```

Opens http://localhost:5173 and calls the FastAPI backend at http://localhost:8000 (start it first; see
the main `README.md`). Set `VITE_API_BASE` to point at a different backend. Open `?ticket=101` to land
on a ticket. Design notes: `../output/design.md`.
